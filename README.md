An Exploratory Data Analysis (EDA) project conducted in **Google Colab** to uncover key factors influencing used-car market valuations.

---

## 📌 Project Overview

Understanding what drives used-car pricing is crucial for buyers, sellers, and automotive platforms. This project analyzes a sample dataset using Python data science libraries to visualize price trends and correlations across vehicle attributes.

---

## 🎯 Key Questions Addressed

1. How strongly does **mileage (km driven)** correlate with vehicle price depreciation?
2. Which **fuel types** (Petrol, Diesel, CNG) retain higher resale value?
3. How much does **vehicle age** impact market price compared to brand reputation?
4. What is the impact of **transmission type** (Manual vs. Automatic) on pricing?

---

## 📊 Key Findings

- **Age & Mileage:** Vehicle age exhibits an exponential decay relationship with price, while mileage shows a steady linear decline.
- **Fuel Type:** Diesel vehicles retain a higher resale price on average compared to petrol variants of similar age.
- **Transmission:** Automatic models command a 15–25% premium in resale market values.
